## Sincronización con Overleaf

No es automática:

- Antes de editar el artículo fuera de Overleaf: en Overleaf,
  *Menu → GitHub → Push Overleaf changes to GitHub*, y después `git pull`
  en la copia local.
- Después de subir cambios a GitHub: en Overleaf,
  *Menu → GitHub → Pull GitHub changes into Overleaf*.
